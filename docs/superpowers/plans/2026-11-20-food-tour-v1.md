# Food Tour v1: Kế hoạch triển khai

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Xây web mobile cho một hội bạn. Web tìm chỗ ăn/chơi/nghỉ, xếp hạng theo Google Places, có Gemini tóm tắt dư luận, và lưu chỗ vào chuyến đi cùng sổ quán chung của nhóm.

**Architecture:**
- Next.js App Router, chia theo tính năng (`src/features/*`). Mỗi tính năng có các tầng `ui → actions → services → repositories`.
- API bên ngoài nằm sau interface trong `src/integrations/*`.
- Supabase lo Postgres, Auth và RLS.
- Cache server 2 lớp: Redis cho dữ liệu nóng, Postgres cho tóm tắt AI.
- Client dùng TanStack Query, lưu cache vào IndexedDB, chạy được như PWA.

**Tech Stack:** Next.js (latest, App Router, TypeScript strict), Tailwind CSS, Supabase (`@supabase/ssr`, `@supabase/supabase-js`, Supabase CLI), Upstash Redis (`@upstash/redis`), Google Places API (New), Gemini (`@google/genai`), TanStack Query + `@tanstack/query-async-storage-persister` + `idb-keyval`, Serwist (PWA), zod, Vitest, Playwright, tsx.

**Spec:** `docs/superpowers/specs/2026-11-20-food-tour-design.md`. Bản mẫu UI: https://claude.ai/artifact/7mmaQ97GDDnux8tZyuYq2N

## Global Constraints

- Ngôn ngữ UI: tiếng Việt. Tên biến, hàm, file: tiếng Anh.
- **Chỉ tối ưu mobile.** Khung app rộng tối đa 480px, căn giữa trên desktop. Vùng chạm ≥ 44px.
- Font **Be Vietnam Pro** (400/500/600/700/800, subset `vietnamese` + `latin`) qua `next/font/google`.
- **Bo góc**: token `rounded-sm` = 4px (nút, ô nhập, chip), `rounded` = 6px (thẻ, khối, nút nổi). Avatar `rounded-full`. Không dùng giá trị bo góc khác.
- **Màu (token Tailwind)**:
  - `ink #1C1B19`, `muted #5F5B54`, `line #E7E3DC`, `surface #F4F2EE`
  - `accent #D9431E`, `accent-strong #B2341A`
  - `good #1E6A4C` / `good-bg #E5F1EB`
  - `bad #8E2A15` / `bad-bg #FBE9E3`
  - `ai #2E4A7D` / `ai-bg #EEF2FA`
  - `warn #7A4B00` / `warn-bg #FBEFD5`
- Không dùng emoji làm icon. Icon là SVG nét (lucide-react).
- Mọi secret, TTL và giới hạn đọc từ env qua `src/shared/config/env.ts`. Có `.env.example` đầy đủ.
- Google Places và Gemini **chỉ gọi từ server**.
- Lưu trữ dữ liệu Google:
  - Bảng `places` chỉ giữ `google_place_id`, `name`, `city`, `address`, `category`, `maps_url`.
  - Điểm, số đánh giá, giờ mở cửa và giá **không ghi vào Postgres**. Chỉ cache Redis tối đa 24 giờ.
- TTL:
  - Kết quả tìm Places: 24 giờ. Place Details: 24 giờ.
  - Tóm tắt AI cho quán: 14 ngày. Quán hot do AI gợi ý: 7 ngày.
- Giới hạn AI: `AI_DAILY_LIMIT_PER_GROUP=10`, `AI_MONTHLY_CAP=300`. Xếp hạng: `RANK_PRIOR_M=50`, `EXPLORE_MIN_REVIEWS=20`. Places: `pageSize=20`, không phân trang.
- **Mục tiêu hiệu năng (mobile 4G)**:
  - LCP < 2s.
  - Chuyển màn < 200ms khi đã có cache.
  - Khám phá < 1.5s khi trúng cache, < 5s khi chưa có cache.
- Không làm ở v1: lịch theo giờ, chia tiền, đặt phòng, trang công khai.
- Commit: chỉ commit khi người dùng đã đồng ý commit trong phiên thực thi. Làm trên nhánh `feat/v1`, không làm trên `main`.

- Create: `src/app/manifest.ts`, `src/app/sw.ts`, `public/icons/*`, `playwright.config.ts`, `e2e/smoke.spec.ts`, `README.md`
- Modify: `next.config.ts` (bọc bằng `@serwist/next`)

**Interfaces:**
- Consumes: mọi màn đã làm.
- Produces:
  - Có manifest: `name: 'Food Tour nhóm'`, `display: 'standalone'`, `theme_color: '#FFFFFF'`, `background_color: '#FFFFFF'`, `lang: 'vi'`.
  - Service worker:
    - Precache app shell.
    - `StaleWhileRevalidate` cho `/_next/static` và font.
    - `NetworkFirst` (timeout 3s) cho trang.
    - **Không** cache `/api/ai/*`.

- [ ] **Step 1:** Cấu hình Serwist + manifest. Chạy `npm run build && npm start` → cài được PWA trên Chrome mobile emulation.
- [ ] **Step 2:** Viết `e2e/smoke.spec.ts` với project `devices['iPhone 13']`. Đăng nhập bằng user test (tạo qua admin), rồi kiểm:
  - mở trang chủ, thấy thẻ "Hải Phòng";
  - vào chuyến, lọc "Chưa chốt" chỉ còn "Sủi dìn";
  - vào Sổ quán, lọc "Không ăn lại" thấy 2 dòng;
  - **không có cuộn ngang** (`document.documentElement.scrollWidth <= 390`).
- [ ] **Step 3:** Chạy `npx playwright test` → PASS.
- [ ] **Step 4:** Chạy Lighthouse mobile (`npx lighthouse http://localhost:3000/ --preset=perf --form-factor=mobile --screenEmulation.mobile`) trên `/` và `/explore`, ghi LCP vào README. LCP > 2s thì sửa trước khi đóng task.
- [ ] **Step 5:** README ghi rõ:
  - các biến env;
  - cách chạy `supabase start`, `db reset`, `seed:haiphong`;
  - cách bật Google OAuth;
  - các lệnh kiểm tra.
- [ ] **Step 6:** Chạy toàn bộ `npx vitest run && npm run test:db && npx tsc --noEmit && npm run lint && npm run build && npx playwright test` → PASS. Commit `feat: pwa, perf check, smoke tests`.
